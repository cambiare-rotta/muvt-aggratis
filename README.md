# MUVT AGGRATIS

Sito della campagna di Cambiare Rotta Bari per trasporti gratuiti, studentati pubblici e affitti sostenibili.
Pubblicato con GitHub Pages: https://cambiare-rotta.github.io/muvt-aggratis/ (repo `cambiare-rotta/muvt-aggratis`)

- `public/`: il sito (HTML/CSS/JS statico, nessuna build)
- `public/assets/`: loghi ottimizzati per il web
- `tools/`: script PowerShell usati per preparare i loghi (`livelli-logo.ps1` per i livelli del logo MUVT esportati da Canva)
- `.github/workflows/pages.yml`: pubblicazione automatica a ogni push su `main`
- `docs/stile.md`: palette, font, linguaggio visivo
- `docs/campagna.md`: contenuti della campagna
- `docs/pubblicazione.md`: come funziona Pages
- `docs/stato.md`: cosa è fatto, parti interattive, collegamenti
- `docs/da-fare-a-mano.md`: cosa non si è potuto fare da qui e come farlo
